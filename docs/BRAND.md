# NetHawk — визуальный стиль

## Название

**NetHawk**

## Знак

Строгий минималистичный ч/б ястреб:

- угловатая геометрия;
- network/circuit линии встроены в силуэт;
- без неона и перегруженного gamer-стиля;
- тёмный фон → белый знак;
- светлый фон → чёрный знак;
- для 16×16/32×32 нужна отдельная упрощённая версия.

Текущие рабочие ассеты находятся в `assets/`.
